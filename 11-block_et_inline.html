les types block et inline en css

un élémént html est de type block ou de type inline

les éléments de type block

les element de types block commence toujours sur une nouvelle ligne et prend donc toute la largeur d'une page

il peuvent contenir d'aure élément de type block ou inline



les paragrape sont de type block

les h1... , les div , les form ... sont de type block

les élémnents de types inline

ils occupent simplement la largeur de leur contenu et ne commence pas sur une nouvelle ligne

on les les strong , em , span , a .. qui sont de type inline
